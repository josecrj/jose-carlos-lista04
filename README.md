# Lista 04 — JavaScript

Exercícios com HTML e JavaScript separados, sem bibliotecas.

| Pasta | Arquivo para abrir |
| --- | --- |
| buscaCep | buscaCep.html |
| listaCidadesAPartirDeEstados | listaCidadesAPartirDeEstados.html |
| detalhaPostagem | detalhaPostagem.html |

Cada pasta contém o HTML e o seu `script.js`. Baixe a pasta completa e abra o HTML no navegador. É necessário acesso à internet para consultar as APIs.

1. **Busca de CEP:** consulta o ViaCEP e mostra rua, bairro, cidade e estado, com mensagens para CEP inválido ou não encontrado.
2. **Estados e cidades:** consulta os estados e municípios no IBGE e mostra a seleção.
3. **Postagens:** consulta os autores, posts e comentários no JSONPlaceholder. Clique no título para ver os detalhes abaixo dele.
